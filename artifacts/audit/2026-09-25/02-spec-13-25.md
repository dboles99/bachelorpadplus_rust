## Biggest gaps (ranked for RC on Windows 10/11 + Linux)

1. **Evidence on the target OSes is missing.** No Windows 11 run anywhere. Linux performance was never measured (`Measure-Startup.ps1` is Windows-only). Win10 numbers are 37 days stale. The latest session has not been through the Windows leg. Time to first interaction is unmeasurable. Needs one RC verification pass on Win10, Win11 and native Linux (GNOME + KDE). **M**
2. **D5 blocks the platform key story**: DPAPI, Windows Hello, Linux Secret Service, Sign Document, and any auto-unlock. That is a whole locked user decision (#12) waiting on one answer. **M–L after D5**
3. **Default-editor integration applies nothing on either OS.** Windows only saves a `.reg` (D8), written UTF-8 without a BOM, which is a non-ASCII-path hazard; the Settings page is shown, not opened. Linux writes files but leaves `xdg-mime`/`update-desktop-database` to the user. There is no icon asset, no unregister, and only 1 of 6 presets is reachable. Also settle D9 (app id) before anyone installs. **M**
4. **Clipboard leakage defect and missing secure clipboard.** The poll harvests other apps' clipboard contents (password managers) into history and menu previews. Copies from Confidential docs flow into Win+V history and cloud sync, even though arboard 3.6.1, already a dependency, has `exclude_from_history/cloud/monitoring`. No timed clearing. **S–M**
5. **Large files and responsiveness.** The large-file engine is unwired, so opening multi-GB loads it all. The default view breaches the frame budget near 40 MB, so the 100 MB target fails. Save is synchronous on the UI thread. `--large-file` / `--readonly` do nothing. **L**
6. **The CLI in the spec is not implemented, with a live bug.** `bachelorpad --line 427 server.log` opens a file named `427`. There is no `bpad` alias. **S**
7. **Clipboard UX per locked decision #11.** There is no editor context menu (history lives in the Edit menu), no clipboard panel, no search, pin is unwired, and YAML/structured types are missing. Native Windows clipboard history needs the `windows` crate. **M**
8. **Security model holes.** Profiles are not persisted across sessions. Custom has no UI. The recent-files list ignores profile and Privacy Mode. The `temporary_files`/`zeroise`/`embeddings` axes are unenforced. There is no auto-lock, no revision history, and no security inspector. There is a stale "off until encryption ships" label. D4 (external envelope review) and D10 (hostile Argon2 cost) remain open before trusting `.bpadx`. **M**
9. **Brand and themes.** No personality/Standard/Minimal modes. No icon/logo at all. The theme choice made in the menu isn't persisted. There are no user theme files and no syntax/notebook/semantic colour roles. **M**
10. **§13 Rust-aware commands: all Missing.** A process runner and output panel are the prerequisite (shared with notebook execution). **L**
11. **No threat-model document**, and fuzzing is not coverage-guided. **M**
12. **No packaging or installer** for either OS (phase 20 not started). This is required for a real default-editor registration and any RC distribution. **XL**
