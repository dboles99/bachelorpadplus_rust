# ADR-0089: The Countdown Counts To The Release

**Status:** Accepted
**Date:** 2026-10-29
**Answers:** D27
**Relates to:** [ADR-0076](../../bachelorpluslite/docs/decisions/ADR-0076.md) (downstream)

## Context

D27 asks: what does the website's countdown count to?

Downstream [ADR-0076](../../bachelorpluslite/docs/decisions/ADR-0076.md) in
`bachelorpluslite` originally said the countdown marked BachelorPad+ arriving on
10 October 2026, which it described as "early-access signup closing".

[V1_1_1_PLAN.md](../project/V1_1_1_PLAN.md) section 1, which produced the
queue that included D27, said the instruction for the plan was that it counted
to **the release**, not to signup closing.

Downstream [ADR-0089](../../bachelorpluslite/docs/decisions/ADR-0089.md)
(withdrawn on 2026-09-25) removed the countdown entirely.

## Decision

**The countdown counts to the release.** This is what the V1.1.1 plan said it
should be, and it is the answer D27 expected.

## Consequences

- If this repository publishes a website, its countdown (if any) targets the
  release date, not any other milestone.
- The downstream ADR-0089's withdrawal of the countdown does not change this
  answer: it changes *that* site's behaviour, not the decision recorded here.

## The lesson

A derived repository's ADRs answer its own questions, and sometimes they
answer them differently. This repository records its own answer to D27.
