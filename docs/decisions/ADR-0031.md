# ADR-0031: Slint is used under its Royalty-free Licence 2.0

**Status:** Accepted
**Date:** 2026-09-25

## Context

Slint is offered under GPL-3.0, the Slint Royalty-free Licence 2.0, or a
commercial licence. The repository never said which applied. The About box
states "MIT OR Apache-2.0", which is true of BachelorPad+'s own code and
false as a statement about the shipped binary, which embeds Slint. Nothing
can be distributed until this is settled (release plan, risk R2).

## Decision

- **Slint: Royalty-free Licence 2.0.** It permits a desktop application like
  this one without making the whole program GPL, in exchange for attribution.
- **Attribution is in the application.** The About window hosts Slint's
  `AboutSlint` element, and the download page may also carry the "Made with
  Slint" badge. The About box is therefore an in-app Slint window, not a
  native dialog: a native dialog cannot host `AboutSlint` (plan M1-02).
- **BachelorPad+'s own code stays MIT OR Apache-2.0.** The About window
  states both: the product's licence, and that the binary includes Slint
  under the Royalty-free Licence 2.0.
- Third-party notices for every shipped crate, including the Slint crates
  and the bundled font (ADR-0032), are generated rather than hand-kept
  (`cargo about`), and `cargo deny` checks the licence set in the gate (plan
  M1-14).

## Consequences

- `LICENSE-MIT`, `LICENSE-APACHE` and `THIRD-PARTY-NOTICES` ship in every
  package.
- **The copyright holder named in `LICENSE-*` is still open.** "BachelorPad+
  contributors" is not a legal entity. Until it is named, the licence files
  are not written.
- Moving to the commercial licence later remains possible. Moving to GPL-3.0
  would relicense the product and is not on the table.
