# ADR-0032: Application id, registration on Windows, and a bundled monospace font

**Status:** Accepted
**Date:** 2026-09-25

## Context

Three platform-integration questions blocked release work (plan decisions 4,
5 and 6): D9, D8, and an unregistered one found by the sixth session.

- **D9.** The application id is this product's identity in every
  `mimeapps.list`, desktop database and AppStream catalogue. Changing it after
  anyone has installed the product orphans every association they made.
- **D8.** `bp-platform` generates the Windows registration values, but the
  app could only save them as a `.reg` file with no undo.
- **Font.** "Consolas" was hard-coded in six places. Slint resolves a family
  name literally -- no fontconfig aliasing, no generic `monospace` -- so
  Linux drew both editor views in a proportional font, and `--editor-view`'s
  one-advance-per-column caret drifted off the text.

## Decision

- **Application id: `io.github.dboles99.BachelorPad`.** Reverse-DNS, with no
  `+`, which desktop-entry ids do not allow. The on-disk directory name
  (`bp_platform::APP_DIR`, `bachelorpad`) does not change: it is a path, not
  an identity, and ADR-0029 has just moved its contents once.
- **Windows registration is the installer's job.** A per-user (HKCU)
  installer writes exactly the values `bp_platform::editor::windows`
  generates, and removes every one on uninstall. The app never writes the
  registry: it reports what opens each type and deep-links to Windows
  Settings (the app's own page on Windows 11, the generic page on Windows
  10). Portable builds keep the `.reg` route, with a matching unregister
  file.
- **DejaVu Sans Mono is bundled** and used on every surface that needs a
  monospace font, on every OS. Its licence (Bitstream Vera, permissive, no
  reserved-name clause) goes into the third-party notices.

## Consequences

- Every `.desktop` file, MIME package and AppStream id uses the new id before
  the first public package (plan M2-05, M2-07).
- The font is one of the few bundled assets, and it moves the binary size by
  roughly 300 KB.
- A test forbids "Consolas" in the `.slint` sources, so the literal-name
  trap cannot return.
