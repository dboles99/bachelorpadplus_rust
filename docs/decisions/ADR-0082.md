# ADR-0082: Hosted CI Is Restored Here Too, On Different Economics

**Status:** Accepted. **The repository setting is Daniel's to flip**
**Date:** 2026-09-10
**Amends:** [ADR-0016](ADR-0016.md)
**Answers:** D25

## Context

[ADR-0016](ADR-0016.md) opens: *GitHub Actions is not available to this
project.* Everything in it follows from that sentence -- the local gate being
authoritative, `.github/workflows/ci.yml` kept dormant at `workflow_dispatch`,
and Actions disabled at the repository level so no branch could queue a run that
could not execute.

**The derived repository disproved that premise for itself**
([ADR-0073 there]) with one API call, and this project inherited the *question*
rather than the answer. Asked here, the answer is different in a way that
matters:

```
GET /repos/dboles99/bachelorpadplus_rust/actions/permissions
{"enabled": false, "sha_pinning_required": false}

GET /repos/dboles99/bachelorpadplus_rust
{"private": true, "visibility": "private"}
```

| | `bachelorpluslite` | **here** |
| --- | --- | --- |
| Actions | `enabled: true` | **`enabled: false`** |
| Visibility | about to be public | **private** |
| Minutes | free, unmetered | **metered**, and Windows bills at **2x** |

**So "not available" is false in the same way it was downstream** -- it is a
switch, and ADR-0016 is the thing that threw it -- **but the cost model is not
the same one**, and that is the half a back-port would have carried over
silently.

**This is exactly the caution the back-port survey was written with**
([V1_1_1_PLAN.md](../../project/V1_1_1_PLAN.md) §2, pass E): *adapt, do not
adopt*. Lite is about to be public, where a full matrix on every push costs
nothing. Here the same YAML would cost roughly **50-60 billed minutes per push**
-- about fifty pushes against a Pro allowance, which is less than one sprint of
the thirty-day plan.

**ADR-0016 was right when it was written**, and nothing about it was careless.
It became false silently, and a decision document has no mechanism that would
ever tell anybody. That is trap 6 for the second time in this project and the
third across the two repositories.

## Decision

**Restore hosted CI, and scope its triggers to what a local gate cannot do.**

```yaml
on:
  workflow_dispatch:
  pull_request:
  push:
    branches: [main]
```

**Not `push:` unqualified**, and the reason is not thrift for its own sake:
authority 2 in `CLAUDE.md` already requires a green *full* local gate before any
push can happen, so re-running the same stages on a feature branch buys minutes
and nothing else. Pull requests and `main` are where an independent machine says
something this machine cannot.

**The local gate stays authoritative.** Hosted CI is not a second opinion on
Daniel's work -- it is the thing a local gate structurally cannot be: **a build
that somebody who is not Daniel, on a machine that is not his, can watch
succeed.** That matters for exactly one thing this project has coming, and it is
D4: an outside reviewer of the `.bpadx` envelope who cannot be asked to trust a
screenshot of a terminal.

### The parity gap is stated rather than implied

Three stages the local gate runs and the hosted one does not: **launch** (a
runner has no display), **log hygiene** (it lives inside `Invoke-LocalCI.ps1`,
and mirroring it would mean a second copy of the rule -- two copies of a rule
drift), and **doctests** as a separate pass, though `cargo test --workspace`
covers them.

**A green run there is necessary and not sufficient**, and the workflow's own
header says so. ADR-0016's warning that two gates which disagree are worse than
one is honoured by naming the disagreement, not by pretending there is none.

### What is not done here

**Actions is still `enabled: false`, deliberately.** Flipping it starts spending
metered minutes on a private repository, which is a decision about somebody's
money rather than about code, and an agent should not make it. The workflow is
correct and will queue nothing until the switch is thrown:

```
gh api -X PUT repos/dboles99/bachelorpadplus_rust/actions/permissions -f enabled=true
```

**If the repository goes public first, this gets cheaper and the scoping above
can be revisited** -- at which point matching Lite's every-push trigger becomes
the obvious choice rather than an expensive one.

## Consequences

**Four places asserted there was no hosted CI and are corrected**: `CLAUDE.md`,
`AGENTS.md` (which is gitignored, so nothing could have caught its drift),
`prompts/rosettas/R011`, and the header of `ci.yml` itself. Each said *"this
**is** CI -- there is no hosted CI"*, which was true and load-bearing for
eighteen ADRs.

**The `-Linux` leg is still a human's to run.** Nothing here changes that a
push needs the full local gate first; the hooks run `-Quick` and the Linux leg
is opt-in, and hosted CI arriving does not make it optional. **A push whose
Linux leg was never run is still a push that skipped half the gate** -- it just
now has somewhere else to be caught.
