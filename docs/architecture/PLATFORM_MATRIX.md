# Platform Capability Matrix

| Capability | Windows 10 | Windows 11 | Linux |
|---|---:|---:|---:|
| Core editor | Yes | Yes | Yes |
| Semantic naming | Yes | Yes | Yes |
| Structured formats | Yes | Yes | Yes |
| Notebook mode | Yes | Yes | Yes |
| `.bpadx` encryption | Yes | Yes | Yes |
| Huge-file mode | Yes | Yes | Yes |
| Hybrid search | Yes | Yes | Yes |
| Native Windows clipboard history | Yes | Yes | No |
| BachelorPad+ clipboard history | Yes | Yes | Yes |
| DPAPI | Yes | Yes | No |
| Windows Hello | OS-dependent | Yes | No |
| Linux keyring | No | No | Desktop-dependent |
| Windows Default Apps handoff | Yes (generic Default apps page) | Yes (the app's own page, `registeredAppUser`, build 22000+) | No |
| File-type registration | `.reg` pair for portable builds (UTF-16LE); installer planned (M3-01; ADR-0032) | Same | `.desktop` + MIME package |
| MIME/default-app integration | No | No | Yes, except in a Flatpak (the sandbox manages it; the row greys) |
| Set as Default: per-user `.desktop` + MIME package, then `update-desktop-database`, `update-mime-database`, `xdg-mime default` after consent | No (the installer registers; ADR-0032) | No (the installer registers; ADR-0032) | Yes, outside Flatpak; no per-user copy when a package installed the entry; Exec is `$APPIMAGE` in an AppImage |
| Remove Registration (removes only the files Set as Default wrote) | No (the `.reg` pair's remove file) | Same | Yes, outside Flatpak |
| What opens a file type today | Readable (`UserChoice`, then the class default) via `bp-platform-windows` | Same | Yes: the full XDG `mimeapps.list` chain, then `mimeinfo.cache` |
| Packaged desktop entry, MIME package and AppStream metadata (`packaging/linux/`, id `io.github.dboles99.BachelorPad`) | n/a | n/a | Yes, generated by `bp-platform` |
| `--version`/`--help` from a shell (release build) | Yes (`AttachConsole`) | Yes | Yes |
| Crash report when there is no console | Log file + message box | Log file + message box | Log file + stderr |

The Windows cells for registration, the association lookup, the console and
the crash box are implemented in `crates/bp-platform-windows` and compile
for `x86_64-pc-windows-msvc`; they have not yet been run on a Windows
machine (release plan M0-12 / M2-03). The deep link's `registeredAppUser`
parameter needs Windows 11 21H2 or 22H2 with the 2023-04 cumulative update,
or 23H2 and later, per Microsoft's "Launch the Default Apps settings page";
an older build ignoring it opens the generic page.
